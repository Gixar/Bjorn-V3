BLE recon

Scan nearby Bluetooth/BLE devices; flags likely trackers.

Uses the Pi's own Bluetooth radio to run a timed passive discovery every so often, and records everything it hears into ble_devices.csv — address, name, and whether the device looks like a finder-network tracker (Apple Find My, Samsung SmartTag, Tile). No extra hardware, no monitor mode, nothing transmitted at a target.

Manual — setup, tuning, and reading the results

Setting it up

  1. Tick Enable BLE scanning and press Save.
  2. Wait one idle window — Bjorn runs standalone modules like this one between scan passes, not on demand.
  3. Press Refresh results. An empty table after a few minutes with phones nearby usually means the Bluetooth radio is down: check bluetoothctl show on the Pi.

The settings

Scan durationHow long each discovery listens. Longer catches more devices — trackers beacon slowly — at the cost of holding the radio. 10–30 s is the useful range.
Min intervalFloor between scans, in seconds. This is a minimum, not a schedule: a scan happens on the first idle window after the interval has elapsed, so the real gap is at least this long and often longer.

Reading the table

TrackerFlagged as a likely finder-network tag rather than an ordinary device.
Detected viaThe evidence. name means the advertised name matched a known product — weak, since names can be changed. A service UUID or manufacturer-data match is the strong signal: it comes from the advertisement itself, which the owner cannot rename.
First / last seenRows are merged by address across scans, so first-seen is preserved. A tracker whose last-seen keeps advancing across many scans is following you; one seen once was just passing.
Google Fast Pair is deliberately not treated as a tracker signature — ordinary headphones advertise it, so it would flag half a train carriage.
Addresses shown may be randomized: both iOS and Android rotate their BLE address periodically, so the same phone can appear as several rows over time. Trackers in lost mode rotate too, but far more slowly.
